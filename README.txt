恐竜アイランド「探そう！宝物」 試作版
======================================

■ 内容
- index.html          参加者用アプリ本体
- assets/chiichan.webp ナビゲーター「ちーちゃん」（軽量化済み）
- qr-maker.html       スタート用1枚＋6か所に置くQR設置カード作成用

■ 試す方法
1. フォルダ内の index.html と assets フォルダを同じ構成のまま公開します。
2. 公開URLの末尾に ?test=1 を付けると、QRを読まなくても6か所を順番にテストできます。
   例：https://example.jp/dino/?test=1
3. 「この端末の進行をリセット」で最初から再テストできます。

■ 本番QRの仕組み
各恐竜のQRは、同じアプリURLに piece パラメータを付けます。
  ?piece=trex
  ?piece=triceratops
  ?piece=stego
  ?piece=brachio
  ?piece=ptera
  ?piece=ankylo

qr-maker.html を開き、公開した index.html のURLを入力すると、スタート用1枚＋6か所用の計7枚のQRカードを作成できます。

■ 運営上の重要ポイント
- 進行状況はスマホのブラウザ内（localStorage）に保存します。
- 参加者はスタートからゴールまで「同じスマホ・同じブラウザ」を使ってください。
- シークレットモード、ブラウザ履歴/サイトデータの削除、別ブラウザへの切替をすると進行が引き継げません。
- 貸出スマホを次の参加者へ渡す場合は、?admin=1 で開いて進行をリセットしてください。
- 個人情報・ログイン・サーバー側DBは使わない構成なので、小規模・短期間イベント向きです。

■ 現在の恐竜とヒント
- ティラノサウルス
- トリケラトプス
- ステゴサウルス
- ブラキオサウルス
- プテラノドン
- アンキロサウルス
ヒント文は index.html 内の dinos 配列で簡単に変更できます。

■ 画像・容量
ちーちゃん画像は 640×640 PNG（約195KB）から 320×320 WebP（約10KB）へ軽量化しています。
アプリ本体は画像以外をほぼHTML/CSS/SVGで描いているため軽量です。
